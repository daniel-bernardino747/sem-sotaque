Para fazer um currículo para uma vaga, eu preciso guardar a vaga. Este aceite vale só para isso; o resto continua como você aceitou no começo.

**O que fica guardado:** o texto da vaga que você colar, a empresa, o cargo e o link, os requisitos que eu tirar dela, o que você marcar como "já usei" ou "não usei" e o currículo de cada vaga.

**Quem lê:** o Daniel, como o resto.

**Por onde passa:** o texto da vaga e o que sai dele vão para a API da Anthropic, como o resto da conversa. O link fica guardado e nunca é aberto daqui.

**Apagar:** cada vaga tem o botão "Apagar esta vaga", e "Apagar meus dados" apaga todas. Fica só a contagem: uma vaga apagada continua contando no limite de vagas.
